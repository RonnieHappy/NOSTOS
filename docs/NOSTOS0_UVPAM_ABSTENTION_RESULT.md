# UV-PAM abstention result

The frozen calibration/semantic test passed its narrow governance endpoint. All 144 sampled UV-PAM tiles lacked physical spacing and lacked support for the requested collagen interpretation. Always-emit and image-QC-only comparators therefore emitted 144/144 and 143/144 silently invalid physical endpoints, respectively. The full contract emitted none.

NOSTOS still produced explicitly pixel-domain descriptors for 125 tiles whose image and perturbation checks passed. These values are labeled in pixels and have no asserted collagen, diagnostic, or cross-modality meaning.

This result demonstrates explicit abstention logic, not measurement accuracy. It is partly deterministic from absent metadata and unsupported semantics and must not be presented as an external accuracy win.
