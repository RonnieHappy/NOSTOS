# NOSTOS-0 3D network stress-test v2 amendment

The v1 corruption series (0, 4, 12, and 32 blocks of 8 x 28 x 28 voxels) produced no case exceeding the frozen 25% endpoint-error definition. Consequently v1 cannot estimate silent-invalid risk or demonstrate contract benefit. Its output is retained.

Before running v2, the corruption series is escalated to 0, 24, 72, and 216 blocks of 24 x 64 x 64 voxels. All endpoint definitions, contract-visible diagnostics, acceptance thresholds, specimen units, and the 25% withheld invalidity threshold remain unchanged. No contract cutoff is retuned.

V2 is a stress-test calibration on the same dataset, not independent confirmation. A publishable claim requires the full contract to reduce silent-invalid risk without merely eliminating all corrupted cases, followed by an acquisition-independent validation.
