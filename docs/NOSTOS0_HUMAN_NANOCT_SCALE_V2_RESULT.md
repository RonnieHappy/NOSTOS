# Human nanoCT scale-response v2 result

Preserving physical scale improved validity but did not pass the frozen operating-envelope gate.

- At 0.20 micrometres, the four-voxel support precondition correctly withheld all measurements.
- At 0.40 micrometres, always-emit risk was 4.17%; the full contract reduced risk to 2.86% but accepted only 36.5% of cases.
- At 0.80 micrometres, always-emit risk was 2.78%; the full contract reduced risk to 0.87% but accepted only 39.9% of cases.

Both supported scales failed the required 80% coverage. Because this redesign followed inspection of v1 failures on the same six volumes, the result is development evidence only. It supports retaining scale-indexed response curves and a Nyquist precondition, but it does not validate the present adjacent-scale cutoff for transfer.
