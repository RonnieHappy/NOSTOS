# NOSTOS-0 3D bone-network contract

Status: frozen after source-metadata and file-integrity inspection, before computing network measurements.

## Measurement domain

The input is an imported multiclass segmentation of rat cortical-bone confocal microscopy. Labels are background (0), canaliculi (1), lacunae (2), and vascular canals (3). The masks were generated by the source authors using U-Net segmentation followed by post-processing correction; they are reference inputs, not manual voxel truth.

Voxel spacing is fixed from repository metadata at z/y/x = 0.30/0.18/0.18 micrometres. NOSTOS must retain this anisotropy and report mask provenance.

## Frozen endpoints

- canalicular skeleton length per tissue volume;
- largest connected skeleton-component fraction;
- branch-node density;
- lacunar object density;
- canalicular volume fraction.

The graph length is the sum of physical lengths of all 26-connected skeleton edges, counting each undirected edge once. No disease or regional biological hypothesis is tested.

## Stress-test cases

Every original central field is paired with deterministic segmentation perturbations: none, sparse local deletion, moderate local deletion, and severe local deletion. Perturbation seeds derive from the sample identifier. The exact deleted fraction is withheld from the acceptance rule.

Contract-visible diagnostics are foreground support, crop-boundary contact, largest-component fraction, and agreement between full and nested central fields. Withheld invalidity is an endpoint error exceeding 25% relative to the unperturbed reference for any of skeleton length density, largest-component fraction, branch density, or lacunar density.

Comparators use the identical estimator:

- always emit;
- endpoint QC using foreground occupancy only;
- topology QC using occupancy plus largest-component fraction;
- full contract using all visible diagnostics;
- component ablations of the full contract.

The primary endpoint is silent-invalid risk at matched coverage, aggregated by rat. Tiles, voxels, and the two anatomical locations are not independent animals.

## Claim boundary

This benchmark tests whether a validity contract detects corrupted imported network masks. It does not validate the source segmentation against histology, establish biological group effects, or demonstrate clinical utility.
